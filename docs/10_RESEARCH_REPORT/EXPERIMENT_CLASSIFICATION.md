# Experiment classification index

All **86** experiment records in `experiments/registry/`, classified by the role each one plays in the frozen champion.

> **The registry itself was NOT reorganised.** Records stay flat in
> `experiments/registry/` because `pipeline/experiment.py` resolves them as
> `EXPERIMENTS_DIR / f"{name}.json"`, `load_all()` globs that directory, and
> `MY_RESEARCH_PAPER/build_paper.py` reads specific records by name. Moving
> them into `accepted/` `rejected/` `archive/` subfolders would break all
> three. This index gives the same navigation with zero risk.

Generated by `research/scripts/08_organization/62_experiment_classification.py`.
